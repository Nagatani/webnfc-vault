使い方概要

外部ライブラリやnpmパッケージは一切不要です。ブラウザ標準の Web Crypto API と Web NFC (NDEFReader) をオブジェクト指向でラッピングしています。js/crypto-vault.js と js/nfc-key-reader.js の2ファイルを ES Modules として読み込むだけで任意のプロジェクトに導入可能です。最小構成の例は demo.html を参照してください。
